Sistema FreeFlow

Protótipo de pedágio automático que conecta leitores RFID e ESP32 a uma API. Registra passagens, identifica duplicidades e disponibiliza cobranças em portais para clientes e concessionárias.

  • Python
  • FastAPI
  • SQLAlchemy
  • ESP32 / RFID
  • scikit-learn
Ver código ↗
Explorar a solução Sistema FreeFlow

O que o sistema faz

  • Recebe eventos de passagem enviados pelos dispositivos ESP32.
  • Aplica uma regra temporal para evitar cobranças duplicadas.
  • Separa as consultas do cliente e a operação das concessionárias.
  • Apresenta dashboard, filtros e exportação de eventos em CSV.
  • Oferece telas demonstrativas de pagamento por PIX e boleto.

Decisões de implementação

O backend utiliza FastAPI e SQLAlchemy, com SQLite na configuração local. As páginas são renderizadas com Jinja2. Um modelo Isolation Forest participa da análise experimental de eventos fora do padrão.

A regra de duplicidade é determinística e independente do modelo. O acesso administrativo limita os dados às faixas associadas à concessionária.

Protótipo acadêmico de TCC. Os pagamentos são simulados e a análise por IA é experimental. Documentação e histórico de contribuições no repositório.

Sistemas distribuídos · Projeto em dupla

API de Pedidos

API para criar, listar e consultar pedidos, além de atualizar seu status. Calcula o valor total automaticamente e organiza a aplicação em camadas de API, serviço e repositório.

  • Python
  • FastAPI
  • PostgreSQL
  • Docker Compose
  • Swagger
Ver código ↗
Explorar a solução API de Pedidos

O que a API oferece

  • Criação de pedidos com validação de quantidade e valor unitário.
  • Consulta por identificador e listagem dos pedidos cadastrados.
  • Alteração para os estados criado, confirmado e cancelado.
  • Cálculo do total e definição automática da data de criação.
  • Documentação interativa e testes manuais pelo Swagger.

Decisões de implementação

A aplicação e o PostgreSQL executam em containers separados. Um volume preserva os dados do banco, enquanto o Docker Compose reúne a configuração necessária para iniciar o ambiente.

Pydantic valida as entradas e SQLAlchemy organiza a persistência. O repositório documenta cenários de erro, alteração de status e verificação da persistência.

Projeto acadêmico desenvolvido em dupla para a disciplina de Desenvolvimento de Sistemas Distribuídos. Integrantes e instruções de execução no repositório.

Explorar a solução SmartStock

O que o sistema faz

  • Cadastra, consulta, altera e remove produtos, categorias e fornecedores.
  • Registra lançamentos e saídas de estoque.
  • Disponibiliza buscas para localizar informações dos cadastros.

Emergy Calc

Aplicação web para cálculo emergético: organiza os recursos de um processo, calcula suas contribuições e apresenta indicadores de sustentabilidade. Permite cadastrar fluxos manualmente ou importar um inventário em CSV.

  • Python
  • FastAPI
  • SQLite
  • JavaScript
  • Pytest
Ver código ↗
Explorar a solução Emergy Calc

O que a aplicação faz

  • Gerencia processos e seus fluxos de recursos.
  • Classifica as entradas em renováveis (R), não renováveis (N) e recursos da economia (F).
  • Calcula a emergia de cada fluxo a partir da quantidade e do valor emergético unitário (UEV).
  • Apresenta totais e os indicadores EYR, ELR e ESI.
  • Importa os dados do inventário a partir de arquivos CSV.

Decisões de implementação

A lógica de cálculo fica separada das rotas da API e dos serviços de dados. O SQLite armazena processos e fluxos, enquanto a interface utiliza Jinja2 e JavaScript.

O código trata indicadores sem denominador válido e inclui testes automatizados com Pytest para a API e a calculadora. A aplicação utiliza uma abordagem didática baseada em UEV.

Projeto acadêmico de Engenharia de Software. Fórmulas, dependências, exemplos de inventário e instruções de testes estão documentados no repositório.
