# Arthur Rodrigues | Portfólio

Portfólio pessoal de Arthur Gomes Rodrigues de Lima, estudante de Ciência da Computação. Reúne minha apresentação, projetos acadêmicos, tecnologias e informações de contato.

[Acessar o portfólio](https://arthurr06.github.io/)

## Tecnologias do site

* HTML5
* CSS3
* JavaScript

Layout responsivo, navegação para celular e currículo disponível em PDF.

## Projetos apresentados

* **[Sistema FreeFlow](https://github.com/ArthurR06/SistemaFreeFlow):** protótipo de pedágio automático com ESP32, RFID e FastAPI.
* **[API de Pedidos](https://github.com/ArthurR06/APIPedidos---Sistemas-Distribuidos):** gerenciamento de pedidos com FastAPI, PostgreSQL e Docker Compose.
* **[SmartStock](https://github.com/ArthurR06/SmartStock):** controle de estoque com Java, Spring Boot e JavaScript.
* **[Emergy Calc](https://github.com/ArthurR06/emergy_calc):** aplicação para cálculo emergético e indicadores de sustentabilidade.

## Executar localmente

Baixe e extraia os arquivos do repositório. Depois, abra o `index.html` no navegador, mantendo a pasta `assets` no mesmo diretório.

Não é necessário instalar dependências ou iniciar um servidor.
