## Projetos

### Sistema FreeFlow | TCC e IoT

Protótipo de pedágio automático com ESP32/RFID, FastAPI e SQLAlchemy. Registro de passagens, regra de duplicidade, portais para clientes e concessionárias e análise experimental de anomalias com Isolation Forest. Pagamentos demonstrativos.

[Repositório](https://github.com/ArthurR06/SistemaFreeFlow)

### API de Pedidos | Sistemas distribuídos

Projeto acadêmico em dupla com FastAPI e PostgreSQL. Criação, listagem e consulta de pedidos, alteração de status e cálculo do total. Arquitetura em camadas, execução com Docker Compose e documentação interativa pelo Swagger.

[Repositório](https://github.com/ArthurR06/APIPedidos---Sistemas-Distribuidos)

### SmartStock | Aplicação web

Sistema de controle de estoque com Java 17, Spring Boot e interface em HTML, CSS e JavaScript. Cadastros de produtos, fornecedores e categorias, movimentações de estoque e autenticação com JWT.

[Repositório](https://github.com/ArthurR06/SmartStock)

### Emergy Calc | Software e sustentabilidade

Aplicação acadêmica com FastAPI e SQLite para gerenciar processos e recursos, importar inventários CSV e calcular emergia e indicadores EYR, ELR e ESI. Inclui testes automatizados com Pytest.

[Repositório](https://github.com/ArthurR06/emergy_calc)
